网关在线 ≠ 飞书连接 ≠ 认证有效 ≠ 模型可调用。本页把四项分开呈现； 认证状态来自官方只读命令 hermes auth status <provider>（按 Profile 分别查询）， Provider 与模型直接读自该 Profile 的 config.yaml。 「模型可调用性」只有在真实推理请求成功后才应视为可用，当前未执行该验证，故显示「待验证」。

生命周期、所有权与本机路径

网关生命周期与所有权
—
所有权模型（严格区分 A / B / C） A 本控制台亲自启动并持续持有 → 关闭控制台不会自动停止它（自动停止能力当前禁用、未通过真实验收；如需停止请在网关卡手动确认）； B 启动控制台前已存在的共享网关 → 永不自动停止； C 你对共享服务的一次性明确授权 → 仅本次生效，不会获得所有权。
—
安全边界
所有权不能由界面直接设定 —— 界面只能请求「启动并接管」或「签发一次性授权」， 真正的判定在主进程 authorizeDangerous() 内完成。 即使绕过界面直接调用 IPC，未经核验的 stop / restart / drain 依然会被拒绝。 渲染进程无 Node 权限，无法发起任意 HTTP 或任意命令；openPath 仅允许白名单目录。
